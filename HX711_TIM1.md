# Чтение HX711 с задержкой через TIM1

Дата: 12 октября 2026 года.

Это последний предложенный в обсуждении вариант. Код ниже ещё не внесён в `Core/Src/hx.c` и не проверен на плате. Документ описывает именно чтение датчика и короткие паузы между фронтами SCK.

## Выбранное решение

HX711 читаем через GPIO: 24 бита, старший бит первым. После данных выдаём 25-й импульс: следующий замер будет на канале A с усилением 128. `HX_Read()` возвращает `false`, если датчик ещё не готов; при `true` новый отсчёт записан по указателю `raw`.

Для пауз выбран TIM1. Он работает как внутренний счётчик; выводы таймера и прерывания TIM1 не нужны. TIM2 остаётся энкодеру.

В текущем проекте TIM1 получает 72 МГц от APB2. Делитель `PSC = 71` даёт шаг счётчика 1 мкс. Период `ARR = 65535` позволяет считать от 0 до 65535.

`HX_Delay()` ждёт два шага счётчика. Если первый шаг наступит сразу после чтения `CNT`, второй всё равно даст полную микросекунду. Поэтому ожидание занимает примерно 1–2 мкс плюс время команд. Приведение разности к `uint16_t` учитывает переход счётчика через ноль.

По одной паузе стоят после поднятия и опускания SCK. Перед первым импульсом тоже есть короткая пауза. После опускания SCK на 25-м импульсе отдельная пауза не нужна: HX711 начинает следующий замер, а SCK остаётся низким.

На время чтения сохраняем маску прерываний и запрещаем обычные прерывания. После последнего импульса восстанавливаем прежнюю маску. Это не даёт обработчику прерывания растянуть высокий уровень SCK.

## Подключение

| Сигнал | Пин STM32 | Режим |
| --- | --- | --- |
| DOUT | PA10 | GPIO input, без подтяжки |
| SCK | PA11 | GPIO output push-pull; между чтениями низкий уровень |
| TIM1 | Внутренний счётчик | Без вывода на GPIO |

## Код для `Core/Src/hx.c`

Ниже сохранён последний предложенный код без смены способа задержки.

```c
#include "hx.h"
#include "main.h"

void HX_Init(void)
{
    __HAL_RCC_TIM1_CLK_ENABLE();

    TIM1->CR1 = 0;
    TIM1->SMCR = 0;
    TIM1->DIER = 0;

    // Для текущего проекта: APB2 без делителя.
    TIM1->PSC = HAL_RCC_GetPCLK2Freq() / 1000000u - 1u;
    TIM1->ARR = 65535u;
    TIM1->RCR = 0;

    // Применяем делитель и сбрасываем счётчик.
    TIM1->EGR = TIM_EGR_UG;
    TIM1->SR = 0;

    // Запускаем счётчик.
    TIM1->CR1 = TIM_CR1_CEN;

    HAL_GPIO_WritePin(SCK_GPIO_Port, SCK_Pin, GPIO_PIN_RESET);
}

static void HX_Delay(void)
{
    const uint16_t start = (uint16_t)TIM1->CNT;

    while ((uint16_t)(TIM1->CNT - start) < 2u)
    {
    }
}

bool HX_Is_Ready(void)
{
    return HAL_GPIO_ReadPin(DOUT_GPIO_Port, DOUT_Pin)
        == GPIO_PIN_RESET;
}

bool HX_Read(int32_t *raw)
{
    if (!HX_Is_Ready())
    {
        return false;
    }

    uint32_t bits = 0;

    // Защищаем импульсы SCK от прерываний.
    const uint32_t irq_state = __get_PRIMASK();
    __disable_irq();

    HX_Delay();

    for (uint8_t i = 0; i < 24; i++)
    {
        HAL_GPIO_WritePin(SCK_GPIO_Port, SCK_Pin, GPIO_PIN_SET);
        HX_Delay();

        bits <<= 1;
        if (HAL_GPIO_ReadPin(DOUT_GPIO_Port, DOUT_Pin)
            == GPIO_PIN_SET)
        {
            bits |= 1u;
        }

        HAL_GPIO_WritePin(SCK_GPIO_Port, SCK_Pin, GPIO_PIN_RESET);
        HX_Delay();
    }

    // 25-й импульс: следующий замер — канал A, усиление 128.
    HAL_GPIO_WritePin(SCK_GPIO_Port, SCK_Pin, GPIO_PIN_SET);
    HX_Delay();
    HAL_GPIO_WritePin(SCK_GPIO_Port, SCK_Pin, GPIO_PIN_RESET);

    __set_PRIMASK(irq_state);

    // Перевод знакового 24-битного числа в int32_t.
    *raw = (int32_t)bits;
    if ((bits & 0x800000u) != 0)
    {
        *raw -= 0x1000000;
    }

    return true;
}
```

## Объявления и вызов

В `Core/Inc/hx.h` нужны эти объявления. Прежнее `Is_HX_Ready()` заменяется на `HX_Is_Ready()`; остальные объявления проекта сохраняются.

```c
#include <stdbool.h>
#include <stdint.h>

void HX_Init(void);
bool HX_Is_Ready(void);
bool HX_Read(int32_t *raw);
```

`HX_Init()` вызывается один раз после настройки частоты и GPIO, в пользовательском блоке `main.c` перед основным циклом:

```c
HX_Init();
```

В основном цикле:

```c
int32_t raw;

if (HX_Read(&raw))
{
    // Здесь новый отсчёт датчика.
}
```

В `HX_Read()` передаётся указатель на существующую переменную `int32_t`. Пока данных нет, функция не ждёт их готовности и не меняет эту переменную. Когда данные готовы, само чтение всех битов выполняется за один вызов.

Функция возвращает сырой отсчёт. Коэффициент калибровки и ноль весов нужны уже для перевода в граммы: `(raw - zero) / factor`. Усреднение, поиск устойчивого веса и текущие вызовы `HX_Read_Average()` в меню требуют отдельной реализации; этот код их не заменяет.

## Новый проект на F0

Для F0 будет создан новый проект. Настройку выбранного таймера и функцию задержки можно сделать иначе, если так код проще, быстрее или меньше. Общий слой с выбором процессора в этом проекте не требуется.

Перед переносом надо задать пины новой платы и частоту счётчика. Формула `HAL_RCC_GetPCLK2Freq()` выше относится к текущему F103 с APB2 без делителя. Для новой платы частоту таймера берём из её дерева тактирования.

## Что подтверждено источниками

- HX711 требует высокий уровень SCK 0,2–50 мкс и низкий не меньше 0,2 мкс; 24 бита данных и 25-й импульс для канала A, усиление 128. [Документ производителя, страницы 4–5](https://cdn.sparkfun.com/assets/b/f/5/a/e/hx711F_EN.pdf).
- Паузы по 1 мкс на обеих половинах импульса есть в [библиотеке bogde, включая путь для STM32](https://github.com/bogde/HX711/blob/master/src/HX711.cpp) и в [статье автора MD_HX711](https://arduinoplusplus.wordpress.com/2023/08/11/weighing-stuff-hx711-weigh-scales-adc-part-2/).
- Растяжение высокого SCK прерыванием разбирают на [форуме ST](https://community.st.com/stm32-mcus-products-25/hx711-load-cell-with-stm32-doubt-4386).
- Настройка счётчика и делителя описана в [руководстве ST по TIM](https://wiki.st.com/stm32mcu/wiki/Getting_started_with_TIM).
